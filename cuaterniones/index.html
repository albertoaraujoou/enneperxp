La superficie

Parametrización clásica por tramos

Los parámetros u y v recorren [0, 2π]. Cada pareja produce un punto (x, y, z). La función se divide en dos tramos para formar el cuello que vuelve y atraviesa el cuerpo.

a = 2(1 − cos(u)/2) Si 0 ≤ u < π: x = 3 cos(u)(1 + sin(u)) + a cos(u) cos(v) z = −8 sin(u) − a sin(u) cos(v) Si π ≤ u ≤ 2π: x = 3 cos(u)(1 + sin(u)) + a cos(v + π) z = −8 sin(u) En ambos tramos: y = −a sin(v)

Es una inmersión de la botella de Klein en tres dimensiones: la zona donde el cuello atraviesa el cuerpo es una autointersección inevitable de esta representación, no un agujero ni un error de WebGL.

La botella de Klein es no orientable: no puede elegirse una normal continua y coherente para toda la superficie. Por eso el material usa DoubleSide. Las normales que calcula la malla son locales y sirven para iluminar, pero no constituyen una orientación global.

API de Three.js

Qué hace cada operación

Quaternion y setFromAxisAngle

new THREE.Quaternion() crea la identidad (0, 0, 0, 1). setFromAxisAngle(eje, ángulo) crea un giro alrededor de un eje unitario; el ángulo se expresa en radianes.

eje.normalize();
incremento.setFromAxisAngle(eje, velocidad * delta);
multiply frente a premultiply

La multiplicación no conmuta. objeto.quaternion.multiply(qΔ) añade el giro después de la orientación actual y hace que el eje viaje con el objeto. premultiply(qΔ) antepone el giro y conserva el eje en el marco del padre; aquí coincide con el mundo porque la botella cuelga directamente de la escena.

normalize

Un cuaternión de rotación debe tener norma uno. Los productos repetidos pueden acumular un pequeño error de coma flotante, por eso el ejemplo llama periódicamente a normalize().

slerp y rotateTowards

slerpQuaternions(origen, destino, t) interpola esféricamente con t entre 0 y 1; el botón “vista A” muestra este recorrido durante 1,5 segundos. Para una velocidad angular constante, rotateTowards(destino, paso) es más directo: avanza un número de radianes por fotograma y nunca sobrepasa el destino. El botón “vista B” muestra esa segunda operación.

copy, clone, invert y angleTo

copy reemplaza los cuatro componentes; clone crea una instancia independiente; invert obtiene la rotación inversa de un cuaternión unitario; y angleTo mide en radianes la separación angular entre dos orientaciones.

setFromUnitVectors y applyQuaternion

setFromUnitVectors(a, b) construye el giro que alinea una dirección con otra. vector.applyQuaternion(q) rota un vector sin modificar una malla; resulta útil para cámaras, direcciones y fuerzas.

Núcleo del bucle

Rotación independiente de los FPS

const delta = Math.min(clock.getDelta(), 0.05);
const angulo = velocidadRadPorSegundo * delta;

incremento.setFromAxisAngle(ejeNormalizado, angulo);

if (marco === 'local') {
  botella.quaternion.multiply(incremento);
} else {
  botella.quaternion.premultiply(incremento);
}

botella.quaternion.normalize();

Multiplicar la velocidad por delta mantiene la misma velocidad perceptiva a 30, 60 o 144 fotogramas por segundo. El límite de 0,05 s evita saltos grandes al regresar a una pestaña que estuvo inactiva.

Notas para producción

La versión de Three.js está fijada para evitar cambios inesperados. En una aplicación real conviene instalarla con npm, servir los módulos desde tu propio paquete y definir una política CSP sin código inline.

El renderizador limita la densidad a dos píxeles físicos por píxel CSS, se adapta al contenedor, pausa al ocultar la pestaña, respeta la preferencia de movimiento reducido y comunica la pérdida del contexto WebGL.

Necesita un navegador con WebGL 2 y acceso al CDN. Sírvelo por HTTP(S); por ejemplo, con npx serve.
